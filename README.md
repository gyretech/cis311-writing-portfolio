# Keshwar White — Technical Writing Portfolio

Static, accessible portfolio prepared for CIS311 Unit 8.1.

## Publish on GitHub Pages
Create a public repository named cis311-writing-portfolio. Commit these files to its main branch. Under Settings → Pages, choose Deploy from a branch, main, and /(root). Submit the live Pages URL shown by GitHub after deployment succeeds.

## Content
Five browser-readable writing samples. Each has a Print / Save as PDF button. No build dependencies or external fonts are required.

Troubleshooting Wi-Fi in Windows 11

A practical troubleshooting guide that makes technical decisions easier to follow.

Professional edition: the final instructions are presented here. The original assignment included a simulated persona review, not observed usability testing. On a managed work device, follow your organization’s support procedures.

Purpose

Wi-Fi problems are common, but the cause is not always the wireless connection itself. The issue could be a setting on the computer, a saved network configuration, the router, or the Internet service. In my professional experience working in information technology and software development, I have learned that troubleshooting is most effective when you eliminate one possibility at a time. These instructions use that same approach, beginning with the simplest checks before moving into more involved troubleshooting.

Before You Begin

A Windows 11 computer.

The name of the Wi-Fi network.

The Wi-Fi password.

Access to another device, such as a smartphone, if available.

Access to the router or modem if it becomes necessary to restart it.

Important Terms

Wi-Fi network: A wireless network that allows devices to communicate with a router without using a physical network cable.

SSID: Service Set Identifier. This is simply the name of the Wi-Fi network that appears in the list of available networks.

Router: The device that allows computers, phones, televisions, and other devices to connect to a local network and usually provides access to the Internet.

Network adapter: The hardware inside the computer that allows it to communicate with a network.

IMPORTANT: Restarting a router is not the same as resetting it. Do not press a button labeled Reset. A factory reset may erase the router's configuration.

1. Turn On Wi-Fi

Go to the lower-right corner of the Windows taskbar.

Select the Network, Sound, and Battery area to open Quick Settings.

Find Wi-Fi. If it is off, select it to turn it on.

Wait several seconds for the list of networks to appear.

2. Make Sure Airplane Mode Is Off

In Quick Settings, find Airplane mode.

Make sure it is Off. Airplane mode disables wireless communication.

If you turn it off, wait several seconds and try Wi-Fi again.

3. Connect to the Correct Wi-Fi Network

Open the available Wi-Fi networks.

Find your Wi-Fi network name (SSID).

Select it and choose Connect.

Enter the Wi-Fi password exactly as provided. Passwords are case-sensitive.

Open a web browser and test a website.

4. Disconnect and Reconnect

Open the Wi-Fi network list.

Select your current network and choose Disconnect.

Wait about 10 seconds.

Select the same network and choose Connect.

Test the Internet connection again.

5. Restart the Computer

Save your work.

Select Start > Power > Restart.

After Windows restarts, connect to Wi-Fi and test the Internet again.

6. Test Another Device on the Same Wi-Fi

Use a phone, tablet, or another computer connected to the same Wi-Fi.

Try opening a website.

If the other device works, continue to Step 7. This suggests the problem is limited to the Windows computer.

If the other device also fails, skip to Step 9. This suggests the problem may involve the router, modem, or Internet service.

7. Forget the Saved Wi-Fi Connection and Reconnect

Go to Start > Settings > Network & internet > Wi-Fi > Manage known networks.

Select your Wi-Fi network and choose Forget.

Important: Forget removes the saved connection only from this computer. It does not delete the Wi-Fi network or disconnect everyone else.

Return to the available Wi-Fi networks.

Select the same network, choose Connect, and enter the password again.

8. Run Windows Network Troubleshooting

Go to Start > Settings > System > Troubleshoot > Other troubleshooters.

Look for the network-related troubleshooter available on your version of Windows 11.

Run it and follow the on-screen instructions.

Test the Internet connection again.

9. Restart the Router or Modem

Use this step if other devices also cannot access the Internet.

Find the router or modem power cable.

Unplug the power cable. Do not press the Reset button.

Wait at least 30 seconds.

Reconnect the power cable.

Wait several minutes for the lights to stabilize and the device to restart.

Reconnect the computer and test the Internet.

10. Get Additional Support

If only the Windows computer still fails, contact IT support if it is a work computer.

If several devices still fail, contact the Internet service provider.

Tell the technician which steps you already completed.
